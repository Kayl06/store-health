# store-health

Shopify store monitoring for agencies: scheduled crawls that catch broken links, slow pages and front-end errors, with alerts only for new problems.

## Getting started

Requires Node 24+ and pnpm.

```sh
pnpm install
pnpm dev        # web on http://localhost:4000, API on http://localhost:4001
pnpm test
```
